# 웹 콘텐츠 주변 프레임 제거

- 변경: 웹 호스트를 상단 도구 모음 스택에서 분리하고 창 콘텐츠의 좌우·하단에 여백 없이 연결했다.
- 이유: 일반 웹 탐색에서 웹 콘텐츠가 창을 최대한 채우도록 한다. 상단 도구 모음의 배치는 유지한다.
- 결정: 하단 고정 상태 표시줄 공간을 없애고 메시지가 있을 때만 웹 위에 표시한다. 입력 오류와 설정·북마크 안내는 보존한다.
- 보존: 원본은 docs/backups/before-web-edge-layout-*에 백업했다.
- 절충: 상태 메시지 표시 중에는 웹 하단 일부를 덮는다.
- 검증: 레이아웃 제약을 확인했다. 실제 화면의 시각 검증은 수행하지 않았다.
- 빌드 검증: `make build` 성공 (`BUILD SUCCEEDED`).
