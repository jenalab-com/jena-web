# 탭 파비콘

- 변경: BrowserEvent와 BrowserTab에 파비콘 바이트를 추가하고 제목 앞에 16pt 아이콘을 표시한다. 빈 탭은 문서, 파비콘이 없는 웹페이지는 지구 아이콘을 사용한다.
- 로딩: WebKit 문서 로드 완료 시 격리된 스크립트 문맥에서 link rel=icon 주소를 최대 8개 조회한다. 후보 실패 시 /favicon.ico를 시도한다. 외부 아이콘 중계 서비스를 사용하지 않는다.
- 수명: 문서 전환 시 이전 아이콘을 초기화하고 요청을 취소한다. 탭 닫기에도 취소하며 응답 적용 전 URL과 페이지 객체를 확인한다.
- 제한: HTTP/HTTPS 아이콘만 조회하며 후보당 10초, 최대 1MiB로 제한한다. URLSession 요청은 WebKit 로그인 쿠키를 공유하지 않으므로 인증이 필요한 아이콘은 기본 아이콘으로 표시될 수 있다. 로드 후 동적으로 바뀌는 아이콘, data/blob 주소, CEF 엔진의 아이콘 조회는 미지원이다.
- 보존: docs/backups/before-tab-favicons-*에 수정한 네 파일의 원본을 보관했다.
- 검증: make build 성공. 실제 사이트의 표시·수신 및 UI 시각 검증은 아직 수행하지 않았다.
