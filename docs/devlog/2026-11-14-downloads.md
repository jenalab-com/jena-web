# WebKit 파일 다운로드

- 변경: 표시 불가능한 MIME 응답, attachment 응답, download 속성의 탐색을 WKDownload로 전달한다. NSSavePanel로 목적지를 선택하고 완료·실패를 안내한다. 완료 안내에서 Finder로 파일을 표시할 수 있다.
- 이유: 파일 링크가 미지원 오류로 끝나는 문제 해결.
- 결정: WebKit 다운로드를 사용해 기존 요청 문맥을 유지한다. 런타임이 다운로드를 보유한다. 저장 취소는 실패 안내를 띄우지 않는다.
- 보존: 변경 전 런타임과 README를 docs/backups/before-downloads-*에 보관했다. 기존 목적지 파일은 삭제하거나 덮어쓰지 않는다.
- 절충: 같은 이름의 파일 선택 시 다운로드를 취소하고 다른 이름으로 다시 시도하도록 안내한다. 진행률 목록, 다운로드 재개는 구현하지 않았다.
- 검증: 제품 Debug JenaWeb 빌드 성공. 실제 사이트 클릭, 저장 패널, 수신 파일 내용, 인증 다운로드의 실행 검증은 아직 수행하지 않았다.
- 환경: Git 저장소가 아니므로 diff 대신 변경 전 파일을 보존했다. 빌드에는 시뮬레이터 버전 및 Swift 언어 모드 관련 환경 경고가 있었다.
