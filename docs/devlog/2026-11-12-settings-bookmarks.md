# 설정 저장과 북마크 연결

사용자의 다음 구현 요청에 따라 검색 설정 저장 및 북마크 흐름을 제품 앱에 연결했다. 변경 전 파일은 docs/backups/before-settings-bookmarks-*에 보존했다.

- AppSettings/SettingsService: 검색 제공처, 웹·이미지 모드, 현재·새 탭 링크 열기 선택을 저장하고 재실행 시 복원한다. 저장 성공 후 엔진 정책을 적용하고, 실패하면 이전 선택으로 되돌려 오류를 알린다. 읽기 실패 시 앱 메뉴에서 재시도할 수 있다.
- Bookmark/BookmarkService: 현재 페이지 저장, 같은 URL 중복 방지, 목록, 수정, 삭제 기능을 추가했다. BookmarkRepository 경계로 DB 구현과 분리했다.
- BookmarksWindowController: AppKit 목록 창, 새 탭 열기, 이름·주소 편집, 확인 후 삭제, 실패 상태와 재시도를 연결했다. 편집 실패 시 입력 초안을 보존한다.
- AppDatabase: Apple SDK SQLite3를 사용한다. 별도 패키지는 설치하지 않았다. 전용 직렬 큐에서 열기·SQL·트랜잭션을 수행한다. 문자열 바인딩으로 입력을 처리하고 DB 오류에 URL·사용자 내용을 노출하지 않는다.
- 저장 경로: 제품 Application Support/AppData/app.sqlite. 웹 프로필에는 접근하지 않는다. 스키마 v1에서 app_setting과 bookmark를 생성한다. 알 수 없는 기존 스키마는 거절하고 자동 삭제·초기화를 하지 않는다. 새 스키마 생성은 트랜잭션으로 처리한다.
- 종료: 설정 또는 북마크 작업 중 창 닫기·⌘Q를 요청하면 진행 중임을 안내하고 종료를 보류한다. 강제 종료나 기존 앱 자동 재시작은 하지 않는다.

앱 단축키 ⌘D(현재 페이지 북마크), ⌘⇧B(목록)를 추가했다. 툴바의 설정 선택이 일반 설정의 진입점이다. 별도 개인정보 화면·방문 기록·사이트 권한 UI는 이번에 구현하지 않았다.

새 DB 파일 생성과 실제 저장은 사용자가 앱을 실행할 때 이뤄진다. 작업 중 기존 사용자 DB나 로그인 데이터를 수정하지 않았다. 사용자 지시대로 기능 테스트·권한 검사·자동 실행 없이 제품 빌드만 수행한다.

제품 Debug 빌드가 완료됐다(build/settings-bookmarks-build.log: BUILD SUCCEEDED). 새 소스 추가 후 Xcode 프로젝트를 재생성해 타깃 파일 목록을 반영했다. 산출물은 build/product/Debug/JenaWeb.app이며 자동 실행하지 않았다. 실제 설정 유지·북마크 동작을 실행 확인했다는 의미는 아니다.
