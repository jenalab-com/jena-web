# 추가된 탭 자동 스크롤

- 변경: 렌더링 전후 탭 ID를 비교해 새 탭을 감지하고, 탭 목록 레이아웃 완료 후 해당 탭 사각형을 scrollToVisible로 노출한다.
- 결정: 추가 시에만 자동 스크롤한다. 제목·파비콘·로딩 갱신에는 사용자의 수동 스크롤 위치를 유지한다. 레이아웃 전 여러 번 렌더링돼도 요청은 유지한다.
- 보존: docs/backups/before-new-tab-reveal-*에 원본을 백업했다.
- 검증: 실제 AppKit 컨트롤로 100개 탭을 순차 추가하며 매번 새 탭 전체가 clipView 안에 있는지 assert했다. 창 폭 800pt 유지, 추가 버튼 가시 범위 유지, 수동 스크롤 뒤 일반 레이아웃의 위치 보존도 통과했다.
- 한계: 제품 전체 창의 수동 시각 검증은 수행하지 않았다.
- 제품 빌드: `make build` 성공 (`BUILD SUCCEEDED`).
