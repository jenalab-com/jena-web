# 주소 입력 글자 세로 정렬

- 원인: NSTextField 자체를 28pt까지 늘리면 한 줄 텍스트와 필드 에디터가 위에 배치된다.
- 변경: 28pt 주소창 배경은 유지하고 내부 입력 필드는 고유 높이로 세로 중앙에 배치했다. 일반 표시·플레이스홀더·편집기가 동일한 입력 필드 위치를 사용한다.
- 상호작용: 배경의 위아래 여백을 눌러도 주소 입력에 포커스를 주도록 했다.
- 보존: 원본은 docs/backups/before-address-text-centering-*에 백업했다.
- 검증 한계: 실제 화면의 시각 검증은 수행하지 않았다.
- 빌드 검증: `make build` 성공 (`BUILD SUCCEEDED`).
