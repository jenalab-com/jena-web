# 사이트 권한·쿠키 설정 화면

- 변경: ⌘, 및 앱 메뉴에 현재 사이트 설정을 연결했다. 주소를 origin으로 정규화하고 카메라·마이크·위치·알림·쿠키의 CEF 적용값 조회와 허용/차단/기본값 복원을 제공한다.
- 이유: 기존 요청 단위 거절만 있던 제품에 사용자 설정 경로를 제공한다. CEF 채택 검증은 다시 수행하지 않는다.
- 결정: 엔진 저장값을 단일 원본으로 사용하며 앱 DB에 중복 저장하지 않는다. 각 항목 변경 후 실제 적용값을 표시한다. 사이트 정책과 OS 권한을 별개로 안내한다.
- OS: 카메라·마이크·위치 상태 표시와 명시적 버튼에 의한 OS 요청/설정 이동. 알림은 UNUserNotificationCenter를 호출하지 않고 시스템 설정으로 이동한다.
- 미디어: 주 프레임 장치 요청만 허용 후보로 삼고 사이트/OS 양쪽 허용을 확인한다. iframe·화면 공유는 요청 단위로 취소하며 다른 저장 권한을 변경하지 않는다.
- 범위: 설정되지 않은 요청은 설정 안내 후 보류한다. 쿠키는 사이트 기본 허용/차단이며 서드 파티 전용 설정은 후속 작업이다. 위치 허용은 정확한 위치를 포함한다. 정책 변경이 진행 중인 캡처를 즉시 종료한다는 보장은 하지 않으며 사용자가 탭을 닫도록 안내한다.
- 빌드: Debug 컴파일·패키징만 진행. 실제 앱 실행, OS 권한 요청, 사용자 프로필 변경, 테스트 실행 없음. 기존 Xcode iOS Simulator 버전 경고는 환경 변경 없이 둔다.
