# 탭 스크롤바 두께 축소

- 변경: 탭 전용 NSScroller에서 손잡이와 트랙의 그리기에 세로 0.5배 변환을 적용했다. 가로 길이·스크롤 위치 계산·마우스 조작 영역은 유지한다.
- 결정: 스크롤바를 잡기 어렵게 만들지 않도록 표시 두께만 절반으로 줄인다. 기존 오버레이·자동 숨김을 유지한다.
- 보존: docs/backups/before-thin-tab-scrollbar-*에 원본을 보관했다.
- 검증 한계: 제품 화면에서의 실제 표시 두께는 시각 검증하지 않았다.
- 검증: 최종 make build 성공. 변경한 스크롤러로 100개 탭 추가·새 탭 자동 노출·창 폭 유지·수동 스크롤 보존 검사를 재실행해 통과했다.
