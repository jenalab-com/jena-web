# 주소 입력 높이와 새 탭 위치

- 변경: 주소 입력 필드를 배경의 위아래에 연결해 버튼과 동일한 28pt 높이를 채우도록 했다. 한 줄 입력을 명시했다.
- 변경: 탭 스크롤 영역은 탭 목록의 실제 너비를 우선 사용하고, 새 탭 버튼 다음의 빈 공간이 남는 너비를 채우도록 했다. 탭이 넘치면 빈 공간이 줄고 목록만 스크롤되며 추가 버튼은 목록 오른쪽에 남는다.
- 결정: 새 탭 버튼은 스크롤 영역 바깥에 유지한다. 기존 링크 설정·북마크 도구의 위치와 기능은 유지한다.
- 보존: docs/backups/before-address-tab-sizing-*에 원본을 백업했다.
- 검증 한계: 실제 화면에서 창 크기 변경 및 다수 탭 스크롤은 아직 확인하지 않았다.
- 빌드 검증: `make build` 성공 (`BUILD SUCCEEDED`).
