# Jena 제품군 디자인 적용

- 참고: jena-image-pro의 HeaderControls.swift·LibraryAppearance.swift, jena-note-pro의 toolbar/HeaderControls.swift. 두 프로젝트는 읽기만 했다.
- 컨셉: 일상적인 웹 탐색을 위한 단색 아이콘, 28pt 컨트롤, 8pt 둥근 회색 배경, 절제된 선택 강조.
- 변경: 탐색·북마크·새 탭·이동 버튼의 모양을 통일하고 주소창에 둥근 배경을 적용했다. 검색 옵션은 기존 메뉴 동작을 유지하면서 테두리와 글꼴을 정리했다. 타이틀바 구분선을 제거했다.
- 탭: 제목과 닫기 아이콘을 하나의 180×28pt 표면 안에 배치했다. 선택 상태는 배경과 글자 굵기로 구분한다. 긴 제목은 말줄임과 툴팁을 사용한다.
- 보존: 기존 탐색 액션·탭 닫기 기능과 웹 가장자리 확장 레이아웃을 유지했다. 원본은 docs/backups/before-jena-design-*에 보관했다.
- 절충: 이미지 앱의 옅은 기본 버튼 배경과 노트 앱의 단색 아이콘을 사용했다. 보조 관리 창은 이번 브라우저 화면 변경에 포함하지 않았다.
- 검증 한계: 실제 화면 시각 검증은 수행하지 않았다.
- 빌드: `make build` 성공 (`BUILD SUCCEEDED`). Swift 컴파일 단계가 평소보다 오래 걸렸으나 완료됐다.
