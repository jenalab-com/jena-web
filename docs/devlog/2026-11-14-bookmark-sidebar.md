# 콘텐츠 왼쪽 북마크 목록

- 변경: 기존 북마크 관리 컨트롤러를 NSViewController 기반 사이드바로 전환했다. 별도 북마크 창 생성·호출을 제거하고 브라우저 콘텐츠 왼쪽에 280pt 영역을 배치한다.
- 동작: 북마크 버튼·기존 메뉴 단축키로 토글하고 상단 닫기 버튼으로 접는다. 열린 동안 웹 호스트가 오른쪽 남은 폭을 사용하며 닫으면 전체 폭을 사용한다.
- 보존 기능: 더블 클릭 및 열기 버튼으로 새 탭 열기, 편집·삭제 확인 시트, 새로고침, 서비스 오류·빈 목록 안내. 목록은 제목과 URL을 두 줄로 표시한다.
- 소유권: 브라우저 창이 사이드바를 보유하며 동일 BookmarkService를 사용해 추가·편집·삭제 결과를 갱신한다. 파일 경로는 기존 빌드 연결을 유지하기 위해 그대로 두었다.
- 보존: docs/backups/before-bookmark-sidebar-*에 수정한 세 파일의 원본을 보관했다.
- 검증: 실제 AppKit 컨트롤러 생성 시 새 NSWindow가 생기지 않는지 확인했다. 280pt 패널의 최소 요구 폭은 176pt로 측정했고 창 폭 1100pt가 유지됨을 assert했다.
- 한계: 제품 화면에서 직접 클릭하는 시각 검증은 수행하지 않았다.
- 최종 검증: 배치 순서 조정 후 make build 성공 (`BUILD SUCCEEDED`).
