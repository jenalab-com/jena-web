# make run 실행 연결

- 원인: 프로젝트 루트에 Makefile이 없어 `make run`이 `No rule to make target 'run'`으로 실패했다.
- 변경: `make build`는 README의 WebKit Debug 빌드를 실행하고, `make run`은 빌드 성공 후 앱을 연다.
- 결정: 기존 CMake 설정과 제품 빌드 경로를 사용한다. `open -n`으로 새로 빌드한 앱을 실행하며 이미 열린 앱을 종료하지 않는다.
- 절충: 실행할 때마다 CMake 구성을 확인하며 실제 컴파일은 증분 빌드를 사용한다.
- 검증: `make run` 종료 코드 0, `BUILD SUCCEEDED`, `open -n` 성공 및 JenaWeb 실행 프로세스를 확인했다.
