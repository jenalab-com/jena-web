# 주소창 포커스 테두리와 탭 높이

- 변경: 주소 필드의 focusRingType을 none으로 설정해 파란 외곽 포커스 테두리를 제거했다. 텍스트 선택·편집 기능은 유지한다.
- 변경: 탭 배경, 탭 스택, 스크롤 뷰포트, 탭 행 높이를 추가 버튼의 공통 높이 34pt로 맞췄다. 탭 행은 centerY로 정렬한다.
- 이유: 탭은 28pt, 목록은 32pt, 추가 버튼은 34pt여서 표시 높이가 달랐다.
- 보존: docs/backups/before-focus-tab-height-*에 원본을 보관했다.
- 검증 한계: 제품 화면 시각 검증은 수행하지 않았다.
- 검증: 최종 변경 후 `make build` 성공 (`BUILD SUCCEEDED`).
