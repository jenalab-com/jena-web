# 영상·로그인 구현 방향 정리

사용자가 CEF로 가능한 방향을 최대한 정리하도록 요청했다. 현재 앱의 TikTok 미디어 오류와 Pinterest 팝업 문제를 분리하고 기존 Swift/AppKit·CEF 구조를 유지하는 방안을 작성했다.

선택: 코덱을 포함한 고정 버전 CEF 배포본을 주 경로로 삼고, 엔진 native popup의 인증 문맥을 보존한다. 기존 패키저의 framework 존재 시 복사 생략을 실제 연결 작업의 선행 수정 대상으로 기록했다. 문서는 docs/cef-compatibility-implementation-plan.md다.

대안: macOS 디코더 전용 구성, AVPlayer, WKWebView 보조 탭, 외부 브라우저. 일반 웹 영상에는 직접 미디어 플레이어 대체가 부적합하며, 두 엔진의 쿠키 공유와 외부 OAuth 세션 전달을 자동으로 된다고 가정하지 않았다. 바이너리 혼용·UA 위장·전역 팝업 허용은 해결 방향으로 택하지 않았다.

범위: 문서 작성과 공개 자료/로컬 코드 읽기. 바이너리 교체·대규모 빌드·실행·새 검증 차수 없음. 정확한 버전 소스 확보, 빌드 자원 산정, 코덱 배포 조건, 실제 사이트 성공 여부는 구현 단계에 남는다.
