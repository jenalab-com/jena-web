# 로그인 팝업의 사이트별 허용

기존에 확정한 엔진 popup의 네이티브 호스트 수용 경로를 유지한다. Pinterest 로그인 무반응 보고를 계기로 무조건 gesture만 검사하는 제품 정책을 보완했다. 사이트 설정의 CEF POPUPS 값을 조회해 클릭 판정이 없는 요청에도 명시적 허용을 반영한다. 저장 원본은 기존과 동일하게 CEF RequestContext다.

Google 도메인 하드코딩이나 전역 팝업 허용은 사용하지 않는다. 목적지 URL만 복사해 새 browser를 만드는 대안도 인증 문맥을 잃을 수 있어 사용하지 않는다. 팝업 기본 차단은 클릭 없는 자동 팝업의 차단을 뜻하며, 사용자 클릭 팝업의 기존 허용은 유지한다. 사이트별 허용은 비인증 자동 팝업에도 적용되므로 UI에서 자동 팝업 허용으로 표시한다.
