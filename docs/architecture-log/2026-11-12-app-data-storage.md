# 설정·북마크 앱 데이터 연결

상태: Accepted. 기존 프로그램 구조의 SQLite 앱 저장소 결정을 실제 코드에 연결한다.

단일 사용자 로컬 앱을 전제로 SettingsRepository와 BookmarkRepository를 각 기능에 두고 AppDatabase가 구현한다. SQLite3는 macOS SDK의 모듈을 사용해 외부 저장 프레임워크 설치 없이 연결했다. CEF 프로필과 앱 DB는 별도 경로다. 사용자 인증 데이터는 앱 DB에 복제하지 않는다.

대안으로 설정만 UserDefaults에 저장할 수 있지만, 기존 기술 설계의 앱 SQLite 경계와 실패 처리를 일관되게 유지하기 위해 설정도 같은 DB에 저장했다. UI MainActor에서 동기 SQL을 실행하는 방식은 선택하지 않았다. AppDatabase는 전용 직렬 DispatchQueue에서 연결을 열고 작업 후 닫으며 Swift async 경계로 결과만 전달한다. 연결 객체는 큐 밖으로 전달하지 않는다.

설정은 저장 중 추가 선택을 막고 성공 시에만 현재 값을 바꾼다. 북마크 URL은 유일하게 관리하고 동일 URL의 재추가는 이름을 갱신한다. 편집으로 이미 존재하는 URL과 충돌하면 SQLite 오류를 알리고 입력을 보존한다. UI는 저장 실패를 성공으로 표시하지 않는다. 저장 작업 중 종료 요청은 보류한다.

v1은 새 DB의 두 테이블만 생성한다. 알 수 없는 버전과 기존 미등록 테이블을 발견하면 거절한다. 향후 실제 기존 DB를 변경하는 마이그레이션은 별도 원본 보존 절차를 추가해야 한다. 이번 구현은 전체 개인정보·기록 기능이나 제품 정책 확정을 의미하지 않는다.
